# Privacy

Passageworks stores account email, a display name, and a password hash for people who register. Sources, extracts, notes, briefs, and annotations stay in the deployment database and in private object storage.

Projects are private to workspace members. A share link is a separate, expiring capability for one brief. It does not publish the library.

If `AI_BASE_URL`, `AI_API_KEY`, and `AI_MODEL` are set, generating a brief sends the instruction and the selected passage text to that external provider. The product states that in the API error and success payloads. Generation can be wrong. Citation id checks do not make it correct.

This build does not send analytics to a third party. The static preview keeps data in the browser tab and does not call a model.

The Northglass Basin material shipped as fixtures is fictional.

A privacy contact and retention schedule for a public deployment are operator decisions. This repository does not invent one.
